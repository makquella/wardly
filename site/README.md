# Сайт Wardly

Статичний лендинг без збірки: `index.html`, `styles.css`, `app.js` і `assets/`;
список героїв із повними підказками — окрема сторінка `heroes.html` (меню «Герої»),
щоб головна лишалася короткою
(шрифти, скриншоти застосунку двома мовами, кадри гри й портрети героїв, іконка, прев'ю для соцмереж).
Усе вантажиться з того самого домену — ні CDN, ні трекерів.

- Українські тексти — в HTML, англійські — в `i18n-en.js` (строгий JSON).
- Звідки прийшов відвідувач: мітка `?ref=<джерело>` у посиланні (`tg`, `reels`,
  `twitch-<нік>` тощо), інакше вид переходу (пошук, відомий сайт, інший, прямий).
  Сайт один раз за візит надсилає лише назву джерела
  (`POST api.luhovyimvp.dev/v1/hit`), кнопки «Завантажити» йдуть через
  `api.luhovyimvp.dev/d/<джерело>` — лічильник і одразу інсталятор останньої версії.
  Підсумки — на `api.luhovyimvp.dev/admin` («Звідки приходять»). Cookie немає.
- Згенеровані сторінки — `python scripts/build_site.py` (потрібні залежності
  бекенда, CI перевіряє `--check`): списки героїв у `heroes.html`, сторінка для
  кожного героя з повними підказками (`heroes/<slug>.html` і
  `en/heroes/<slug>.html`: темп добивань, пороги HP, порятунки, порада — ті самі
  цифри, що в тренера в грі), англійські копії `en/index.html` і
  `en/heroes.html` з українського HTML та `i18n-en.js`, `sitemap.xml`. Вручну їх не
  правити; після правки `index.html`, `heroes.html`, `i18n-en.js` або профілю
  героя — перезапустити скрипт.
- Мова: у кожної сторінки є пара іншою мовою; перемикач UK/EN
  відкриває її (мітка `?ref=` зберігається), обрана мова запам'ятовується.
- Номер версії й розмір під кнопкою беруться з останнього релізу GitHub
  (`api.github.com/repos/makquella/wardly/releases/latest`). Для відвідувачів
  репозиторій має бути публічним.
- Картка підказки на першому екрані показує справжні тексти порад
  застосунку.
- `changelog.html` («Що нового») збирається з `docs/release-notes/` командою
  `python scripts/build_changelog.py` (шаблон — `scripts/changelog.template.html`).
  Вручну не правити: CI звіряє сторінку з нотатками.

## Подивитися локально

```bash
cd site && python3 -m http.server 8080
# http://localhost:8080
```

## Адреса: luhovyimvp.dev

Сайт публікується на GitHub Pages (`.github/workflows/pages.yml`): сам після
кожної зміни `site/` у main, після нових дописів (мета, патч, герой тижня) або
вручну (Actions → *Website* → Run workflow). Відкривається за адресою
`https://luhovyimvp.dev`.
DNS домену — у Cloudflare, записи йдуть **через проксі Cloudflare** (помаранчева
хмара): HTTPS видає Cloudflare, GitHub віддає сторінки.

- `A` для `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`,
  `185.199.111.153`; `AAAA` для `@`: `2606:50c0:8000::153` … `2606:50c0:8003::153`;
  `CNAME` для `www` → `makquella.github.io`.
- У Cloudflare: SSL/TLS → режим **Full** (не Flexible і не Full strict),
  **Always Use HTTPS** увімкнено. Позначка «Enforce HTTPS» у GitHub за проксі
  недоступна й не потрібна.
- Записи пошти (MX, TXT для Migadu) не чіпати.
- Якщо сайт не відкривається в частини гравців (деякі провайдери сповільнюють
  ресурси за Cloudflare), перемкніть записи в «DNS only» (сіра хмара), а в
  GitHub → Settings → Pages увімкніть Enforce HTTPS, коли випуститься сертифікат
  (до години; домен `.dev` без HTTPS не відкривається).

Канонічна адреса й прев'ю посилання (`og:image`) в `index.html` указують на цей
домен. Інший хостинг: досить викласти вміст `site/` у корінь сайту.

## Оновити картинки

Усі картинки сайту — справжні: вікна застосунку (`assets/app/{uk,en}/`),
картки оверлея (`assets/overlay/{uk,en}/`) і картки розбору
(`assets/shots/{uk,en}/`) знято із самого застосунку на демо-даних; кадри гри
(`assets/game/`) — зі сторінки Dota 2 у Steam, портрети (`assets/heroes/`) — з
CDN Valve, ті самі, що показує застосунок. Перезняти все:
`scripts/site-shots/README.md`.

Шрифти: Montserrat (заголовки) й Inter (текст), обидва OFL, лежать в `assets/fonts/`.
