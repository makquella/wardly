## Що нового

- **Довші звіти й ідеї.** У звіт про проблему тепер уміщується до 2000 символів (було 1000), під полем є лічильник символів. Поле називається «Що сталося або ідея?»: туди можна писати й пропозиції — гравці вже надсилають ідеї, дякуємо!

Інсталятор поки без цифрового підпису: якщо Windows покаже «Windows захистив ваш комп'ютер», натисніть «Докладніше» → «Однаково запустити». Встановлена версія оновиться сама, коли Дота буде закрита.
