## Сигналы и работа с неизвестными данными

- **own_resources** (existing): Собственные health/max_health/mana, alive; только присутствующие валидные поля текущего payload.
- **own_abilities** (existing): raw_name, learned level, cooldown, can_cast; проверять фактическую возможность применения, не подменять целью.
- **own_status** (existing): Наблюдаемые stun/hex/silence/mute и другие флаги. Отсутствующий флаг не считать подтверждённым false.
- **own_inventory** (existing): Слоты и доступность собственных предметов, включая TP; это не рекомендация билда.
- **position** (existing): Собственные координаты только при наличии; некоторые player payload их не содержат.
- **hp_history** (existing): Динамика HP/маны из MatchMemory и записи; падение HP не всегда означает вражеский урон.
- **visible_enemies** (existing): Текущие видимые враги и часть координат minimap; отсутствие не раскрывает скрытых врагов и их cooldown.
- **match_clock** (existing): Идентификатор сессии, время игры и пауза для отмены устаревшего плана.
- **charges** (raw_extension): charges/max_charges/charge_cooldown есть в real_player_ranked.json, но normalizer их теряет. Требует проверки на выбранном герое.
- **upgrades_talents** (raw_extension): hero.aghanims_scepter/aghanims_shard/talent_* есть в реальных семплах. Нужны нормализация, сопоставление и контракт отсутствующих данных.
- **effective_costs** (new_observation): Затраты и длительности по уровню с подтверждёнными модификаторами. Базовые значения Valve недостаточны при неизвестном изменении.
- **cast_history** (new_observation): Подтверждённые применения/события способностей. Переход cooldown сам по себе не подтверждает попадание или наличие эффекта.
- **active_effects** (new_observation): Наличие, остаток времени и величина щита/баффа. Cooldown не доказывает активность; packets/refreshes/modifiers учитываются.
- **action_intent** (manual_or_replay): Подтверждённая задача: рискованная пачка, бой, сброс на базу. По одному движению нельзя уверенно восстановить намерение.
- **remnant_anchor** (manual_or_replay): Существующие remnants, позиции, время создания/истечения и текущая обстановка точки. Заряды этого не заменяют.
- **wave_units** (raw_extension): Minimap игрока даёт тип и позицию своих лейн-крипов всегда, вражеских и нейтралов — только в видимости (minimap_units.py, farm_map.py с 0.61.0); HP крипов, состояние лагеря в тумане и стаки неизвестны.
- **target_state** (manual_or_replay): Состояние выбранной цели, расстояние, видимость, применимость действия, иммунитет/блокировки; не считать это известным по имени героя.
- **enemy_control** (manual_or_replay): Фактические условия начала/продолжения контроля, доступность и источник наблюдения. Статический драфт описывает возможность, а не готовность.
- **allied_units** (manual_or_replay): Позиции/HP/состояния и задачи союзников; player GSI их сейчас не подтверждает.
- **controlled_units** (manual_or_replay): Позиции, ресурсы и состояние ward/иллюзий; нельзя выводить их только из cooldown способности.
- **projection_body** (manual_or_replay): Состояние тела/духа Dazzle, tether, точка возврата; новая механика требует проверки реального представления и ограничений.
- **autocast_mode** (new_observation): Alt-cast Storm Hammer не подтверждён перечисленными семплами. Нужен реальный источник режима; наличие улучшения не означает полёт.

`existing` означает наличие источника при корректном текущем payload, а не
безусловную доступность на каждом tick. `raw_extension` — поле есть в реальном
семпле, но нужно сохранить и проверить в контракте. `new_observation` — нужны
новые наблюдения/трекер. `manual_or_replay` — точная команда заблокирована до
подтверждённого источника; послеигровая информация не используется как live-факт.

## Воспроизводимость

```bash
python scripts/hero_advice_research.py validate
python scripts/hero_advice_research.py render --check
```

Тексты карточек подготовлены на украинском и английском. Каталоги — данные
исследования, которые live-пайплайн не загружает. Источники привязаны к патчу
и контрольной сумме; числовые утверждения и цитаты сверяются автоматически.
Пустой список facets в этих снимках не разрешает придумывать модификаторы.

Подробный порядок реализации и границы сделанной проверки — [IMPLEMENTATION.md](IMPLEMENTATION.md).
